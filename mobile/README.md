# CollabHub Mobile

Expo React Native starter for the CollabHub brand/influencer marketplace.

## What is included

- Premium mobile demo UI
- Brand/influencer role switching
- Campaign marketplace
- Creator discovery
- Application review
- Messaging demo
- Profile screen

This first version uses local in-app demo data so mobile UI can be tested before wiring Convex, Stripe, Google, and Apple auth.

## Run

```bash
cd mobile
npm install
npm start
```

Then open in Expo Go, iOS simulator, Android emulator, or web.

## Checks

```bash
npm run typecheck
```
